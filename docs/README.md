# docs/ の索引

| ファイル | 中身 | いつ読むか |
| :--- | :--- | :--- |
| `design.md` | 実装が守る制約(決定済み・理由つき)と、まだ決まっていないこと | 面を足す・消す・結線を変える前 |
| `decisions.md` | 面ごとに選んだことと理由。面を足す/減らす判定基準の運用 | 既存の面を触る前、「なぜこうなっているか」を知りたいとき |
| `database.md` | Supabase の権限(service_role と `auth.uid()`)・migration の運用・`gen types`・観測・暴走クライアントの止め方・障害記録 | migration を書く前、DB の異常を調べるとき |
| `supabase-backup.md` | 定期/手動バックアップ、本番→ローカル同期、復元(inbox の直前値、dead tuple からの復元) | バックアップを取る/戻すとき |
| `directory_structure.md` | ディレクトリ構成・フォルダの役割・開発フロー・コーディングスタイル | 新しいファイルを置く場所に迷ったとき |

コードの特定行に紐づく罠(PostgREST のキー集合・`+` のエンコード、楽観ロックの戻り値の符号、自動保存の effect 依存など)は、そのコード・migration のコメントが正。ここの文書はそれらを重複して書かず、参照先を示すだけにする。実装済みの構造・投入経路・禁止事項はリポジトリ直下の `README.md`。
