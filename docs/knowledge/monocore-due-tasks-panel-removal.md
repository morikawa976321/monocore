# 判断: monocore schedulesの要注意タスクパネル削除

**選択**: monocore v2 Phase 2で入れた「schedulesページに今日期限・期限切れタスクを差し込み表示する」パネル（見出し「要注意タスク」）を、パネルごと全削除した（2026-07-17）。期限切れ行だけ消す案もあったが、パネル自体を消す方を選択。締切の確認はtasks画面に一本化。

**理由**: 認知負荷が無駄に上がるだけだった。「毎日見る唯一の面に集約すれば通知機能の不在を代替できる」という当初の設計仮説が、実運用では成立しなかった。

**位置づけ**: [[digital-improvement-stance]] の言う「実験→資産への昇格ゲート」で不合格を出した実例。作って本番反映した機能を、使ってみて要らないと判断して消している。[[simple-life-minimalism-goal]] の認知負荷ゼロ化目標がデジタル領域でも適用された形。

**影響**: Phase 2の価値「通知機能の不在を毎日見る唯一の面への集約で代替」は未回収のまま Phase 3（チャット窓口）に持ち越し。Phase 2で残ったのは `updated_by` によるAI編集識別のみ。
